# Methods Lab Activity – Math Program -- Christine Angel B. Robillos

## Description
This project is a Java-based Math Program that demonstrates the use of methods, parameters, return values, conditional statements, and loops. It performs different mathematical operations using reusable methods.

## Objectives
- Declare and call methods.
- Differentiate `void` and return-value methods.
- Pass arguments and use returned results.
- Organize mathematical computations into reusable methods.
- Apply loops and conditional statements in Java.

## Features

### Task 1: Introduction
- Displays a welcome message using a `void` method.

### Task 2: Arithmetic Methods
Performs basic arithmetic operations:
- Addition
- Subtraction
- Multiplication
- Division

### Task 3: Factorial
- Calculates the factorial of a given number.
- Uses a `do-while` loop.
- Checks for invalid negative inputs.

### Task 4: Sum
- Accepts five numbers from the user.
- Calculates and displays their total using a method.

### Task 5: Prime Number
- Checks whether a number is prime or not.
- Uses a Boolean method with `if-else` statements and a `while` loop.

### Task 6: Maximum Number
- Allows the user to enter the number of values.
- Identifies and displays the largest value using comparisons.

### Task 7: GCD and LCM
- Calculates the Greatest Common Divisor (GCD).
- Calculates the Least Common Multiple (LCM).

## Additional Challenges

**Challenge 1: Recursive Factorial**
- Calculates factorial using recursion.

**Challenge 2: Fibonacci**
- Generates a Fibonacci number using recursion.

**Challenge 3: Palindrome**
- Checks whether a word reads the same forward and backward.
- Ignores uppercase and lowercase differences.

## Java Concepts Used
- Methods and method calling
- Static methods
- Void methods
- Parameters and arguments
- Return values
- Integer, double, and Boolean data types
- If-else statements
- While loops
- Do-while loops
- Recursion
- Scanner class for user input

## Requirements
- Java Development Kit (JDK)
- NetBeans IDE or any Java-compatible IDE

## How to Run
1. Clone or download this repository.
2. Open the project in NetBeans or your preferred Java IDE.
3. Open `MethodsLab.java`.
4. Run the program.
5. Enter the requested values in the console.
